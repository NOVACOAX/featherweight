Convert linkbreeze to pnpm?

Your installed versions stay exactly the same. pnpm keeps one shared copy of each package, so this project will use less space.

  • 1Back up package-lock.json so you can revert
  • 2Create pnpm-lock.yaml from it (pnpm import)
  • 3Reinstall node_modules with pnpm
  • 4Check that the project's install succeeded
Anyone who clones this project from GitHub will need pnpm to install it.
